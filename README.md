# 📊 Data Visualization & Dashboard using Power BI

## 📌 Project Overview

This project focuses on analyzing sales data and creating an interactive dashboard using Microsoft Power BI.

The goal is to transform the sales data into meaningful visualizations that help understand sales performance and business trends.

## 🎯 Objectives

- Analyze sales data using Power BI
- Create meaningful charts and visualizations
- Identify important sales trends
- Build an interactive dashboard
- Present business information in an easy-to-understand format

## 🛠️ Tools & Technologies

- Microsoft Excel
- Microsoft Power BI
- Data Visualization
- Business Intelligence

## 📊 Dashboard Features

The Power BI dashboard includes:

- Sales performance analysis
- Interactive charts
- Category-wise analysis
- Data filtering
- Visual representation of sales information
- Interactive dashboard elements

## 📂 Project Files

| File | Description |
|---|---|
| `ACME Sales Report.xlsx` | Source sales dataset |
| `raj.pbix.pbix` | Power BI dashboard file |

## 🔄 Data Analysis Workflow

```text
Excel Sales Data
       ↓
Data Preparation
       ↓
Import into Power BI
       ↓
Create Visualizations
       ↓
Build Interactive Dashboard
       ↓
Generate Business Insights
```

## 📈 Dashboard Preview

The project contains an interactive Power BI dashboard created using the sales dataset.

The `.pbix` file can be opened using Microsoft Power BI Desktop to explore the dashboard and interact with the visualizations.
